# レビュアー依頼テンプレート

すべての依頼で、少なくとも `目的 / 対象 / 制約 / 依頼内容 / 期待出力` を渡す。

## Tester 依頼

```md
## テスト対象
- 目的:
- 対象:
- 制約:

## 期待動作
- 期待:

## 依頼内容
- 実行してほしいテスト:
- 手動確認してほしい観点:

## 期待出力
- 実行可否:
- 結果:
- 未実施項目:
- 理由:
```

## Structure Reviewer 依頼

```md
## レビュー対象
- 目的:
- 対象:
- 制約:

## 依頼内容
- ディレクトリ構成を確認する。
- ファイル命名を確認する。
- 責務境界を確認する。
- 不要なネストの有無を確認する。

## 期待出力
- 問題の有無:
- 推奨対応:
- 総評:
```

## Security レビュー依頼

```md
## レビュー対象
- 目的:
- 対象:
- 制約:

## 依頼内容
- 認証 / 認可を確認する。
- 入力検証を確認する。
- 秘密情報の扱いを確認する。
- 権限境界を確認する。
- 外部通信 / 依存関係を確認する。

## 期待出力
- 重大度:
- 指摘:
- リスク:
- 推奨:
```

## UX レビュー依頼

```md
## レビュー対象
- 目的:
- 対象:
- 制約:

## 文脈
- 想定ユーザー:
- 主要ユースケース:
- ユーザー接点の種類:

## 依頼内容
- UX 観点を確認する。
- Design 観点を確認する。

## 期待出力
- UX 指摘:
- Design 指摘:
- 残懸念:
```

## Spec Reviewer 依頼

```md
## レビュー対象
- 目的:
- 仕様書 / 設計書:
- 実装ファイル:
- 制約:

## 依頼内容
- 仕様に書かれた挙動が実装されているか確認する。
- 仕様にない挙動が追加されていないか確認する。
- インターフェースと制約が一致しているか確認する。

## 期待出力
- 問題の有無:
- 乖離の種類:
- 推奨修正:
```
